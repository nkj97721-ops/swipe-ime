# SwipeIme

Android 原生中文输入法：26 键拼音输入 + 滑行输入轨迹。

## 当前功能
- Android InputMethodService
- 26 键 QWERTY 拼音输入，拼音预输入显示在编辑框
- 中文候选词与本地词库（CI 构建时生成）
- 九键数字与符号面板
- 滑行轨迹绘制、路径解码与候选词
- 单手模式、剪贴板历史、常用语、光标工具
- 轨迹外观参数调节

## 工具栏
第二工具行：
- 清空
- 全选并复制
- 剪切
- 粘贴并回车
- 撤销

第三工具行保留段首、行首、左右移动、行尾、段尾。

## 构建
GitHub Actions 在每次 push 或手动触发时构建 Debug APK，产物名为 `SwipeIme`。

## 注意
Debug 构建成功不代表已完成真机兼容性验证。请在 Android 设备上启用输入法后测试常用输入框、滑行识别和工具栏操作。
