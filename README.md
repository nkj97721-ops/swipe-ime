# SwipeIme

Android 本地中文输入法，面向 Android 8.0 及以上设备。

## 当前功能

- 26 键 QWERTY 拼音输入，拼音预输入显示在编辑框中
- 本地中文词库、完整拼音候选、模糊拼音与首字母简拼
- 依据用户主动选词形成的本机上下文词频排序
- 轨迹绘制与后台滑行解码
- 九键数字面板与符号面板
- 剪贴板历史、常用语、光标左右移动工具
- 空格键拖动整个键盘面板，松手保持位置，不改变按键尺寸
- 黑色界面与轨迹外观设置

## 工具栏布局

第一工具行：左移、剪贴板、常用语、右移。

第二工具行：全选并复制、隐藏键盘、粘贴并回车。

## 隐私

- 密码输入框和设置了 `IME_FLAG_NO_PERSONALIZED_LEARNING` 的输入框不显示拼音候选。
- 上下文词频只保存在本机；仅在普通输入框中主动选词时更新。
- 敏感输入框不记录剪贴板历史或上下文选词。

## 词库来源与许可

词库由 [iDvel/rime-ice](https://github.com/iDvel/rime-ice) 的 `8105`、`base`、`ext` 字典生成。
构建固定在提交 `927e1cf1d3eeb9bf4be85e3f684dba4dd485b6f6`，避免上游分支变化导致同一源码产生不同词库。
词库遵循 GNU GPL v3，许可文本见 [LICENSES/GPL-3.0.txt](LICENSES/GPL-3.0.txt)。

## 构建与测试

GitHub Actions 在 push 时运行词库生成、`testDebugUnitTest` 和 Debug APK 构建。
自动测试覆盖完整拼音、模糊拼音、简拼、大写归一化和模糊匹配边界。

Debug 构建成功不等于已完成真机兼容性验证。仍需在设备上验证不同输入框、滑行识别和键盘拖动。
